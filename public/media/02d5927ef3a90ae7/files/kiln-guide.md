# Seven courses for building and evaluating AI agents

Researched 2026-11-12.

## Strengths and best use

The list's strongest feature is its range from team practices to practical agent exercises. It provides options for Python developers, teams trying visual workflows and learners preparing an MCP integration.

## Current checks

Claude Platform 101 covers the API and Claude Code 101 covers the coding agent. Take the MCP introduction if clients, servers and tools are unfamiliar. Microsoft describes its Applied Skills credential as an assessment and expects experience with Microsoft Foundry agents. MongoDB's badge page lists its earning criteria. Course enrollment and the cost of following along can differ.

## Project idea

Start with the team course and one tooling track. Build an agent that uses a read-only fixture and log its tool calls. Add input validation, timeout handling and an evaluation of one failure scenario. Estimate lab time separately from lesson video time.

## Reusable prompt

```text
Give me a course sequence for an agent project. Specify which parts need code, a paid account or a lab, and show how I can demonstrate one capability from each completed course.
```
