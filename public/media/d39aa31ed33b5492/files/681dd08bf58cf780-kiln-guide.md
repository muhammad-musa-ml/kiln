# Design references for brief writing and motion prototypes

Researched 2026-11-12.

## Strengths and best use

Prompt Motion pairs examples with creation direction. Eyecandy gives visual techniques names you can communicate. React Bits provides working React component examples. Together they help turn a vague redesign request into a small, observable brief.

## Current checks

The reel uses different sites to illustrate its before and after, so it cannot establish turnaround time or effect. Check a component's dependencies and the repository's current license before copying code. Capture references with URL, author and intended technique. Verify interaction and fallback behavior in your own stack.

## Project idea

Select a single motion or layout technique. Describe its trigger, duration, what it should communicate, and the mobile and reduced-motion fallback. Build the smallest prototype and compare it against a static baseline with the same content.

## Reusable prompt

```text
Build a one-screen brief using these references. Extract a specific technique from each, describe what it communicates, and include a no-motion fallback plus two observable tests.
```
