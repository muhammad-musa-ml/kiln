## Project idea

Read one official listing per company and record whether the link opens an application, a general portal, or a careers index. Use the requisition ID to detect a replacement or duplicate. Compare role scope with portfolio evidence and review work arrangement before applying.

## Reusable prompt

```text
Create a dated shortlist using official requisitions. Verify title, location, work arrangement, application status and requirements. Keep company-only leads separate from roles with an application page.
```
