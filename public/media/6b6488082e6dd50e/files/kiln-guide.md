The seven-day list connects AI foundations with Claude Code, MongoDB, LangChain, Hugging Face agents and advanced MCP. Each can support a small build that provides more context than a credential name alone.

## Project idea

Choose a track and make a simple calendar. Confirm the provider's badge or assessment rules, credentials needed to follow along, and whether a cloud lab incurs usage costs. Pair a course with a small reproducible demo, then use the credential's exact name on a resume.

## Reusable prompt

```text
Build a course plan for six hours this week. Record each provider's credential type, prerequisites and estimated study time, and pair the first two courses with a demonstrable exercise.
```
