# Code-driven video skills for four distinct outputs

Researched 2026-11-12.

## Strengths and best use

Bang Motion fits a browser preview and animated typography. The motion-graphics-skills pack includes a sourced Vox-style explainer. Huashu Art Motion offers parameterized animated paintings. Claude Drawing Skill offers procedural illustration and documents draw-on GIF output.

## Current checks

Multiple repositories use the Vox name. The charlie947 pack uses code and can export through HyperFrames. The CK42BB version uses Atlas Cloud generation services. Review the requested repository, package and provider requirements before installation. Local render dependencies and model usage still affect effort and cost. The creator's gated Vox link is unconfirmed.

## Documented setup references

```sh
npx skills add charlie947/motion-graphics-skills
```

## Project idea

Try a six-second typography scene with a title, one transition and an ending hold. Record render time, frame pacing, text legibility and any service calls. Then test two renders from identical inputs to check determinism. Track image, font, soundtrack and voice permissions separately.

## Reusable prompt

```text
Compare these repositories for a six-second preview. Give me the runtime and output of each option, the assets it uses, and checks for legibility, timing and licensing.
```
