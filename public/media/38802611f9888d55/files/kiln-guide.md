# App marketing: measure activation before scaling distribution

Researched 2026-11-02.

## Turn the ten levels into experiments
The reel moves from telling friends and posting on LinkedIn to launches, directories, short videos and automated follow-up. That is a menu of distribution channels, not a validated staircase everyone must complete. Its revenue, posting-volume and zero-ad-spend examples are claims; organic distribution still consumes production and support time. This independent guide was checked November 2, 2026.

Start with one audience, one problem and one action worth measuring: a completed setup, a qualified trial or a purchase. A signup without activation may hide onboarding friction. More impressions will not repair that problem by themselves.

## A practical progression
| Stage | Small experiment | Decision evidence |
| --- | --- | --- |
| Understand | Show a working task to a few suitable people | Their own description of the problem and current workaround |
| Explain | Publish one specific use case and demo | Qualified visits reaching the intended page |
| Activate | Improve one onboarding step | Fraction completing the first useful action |
| Distribute | Try one directory, launch or content channel | Activated users and support burden from that channel |
| Repeat | Reuse the strongest message with a new example | Retained use across a defined follow-up period |

Ten directory submissions are not a ranking threshold. Use a directory because its audience fits, and record the time spent. Keep campaign labels consistent, avoid personal data in URLs, and separate a platform's view count from product events. Compare cohorts over the same follow-up window before declaring a winner.

## SEO and AI discovery
Useful crawlable content, ordinary internal links and accurate page information remain foundations. Google's [SEO starter guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide) and [AI features guidance](https://developers.google.com/search/docs/appearance/ai-features) do not prescribe a special AI file or a directory quota for inclusion. Allowing a crawler does not guarantee recommendation, indexing or traffic. See the separate SEO checklist tile for implementation and verification.

## Reels and follow-up
Meta's [Trial Reels announcement](https://about.fb.com/news/2024/12/trial-reels-try-content-non-followers-first-see-what-perfoms-best/) describes testing content with non-followers and reviewing performance. Check availability in the actual account. Treat a trial as one messaging experiment; it does not guarantee audience growth. Change one element, such as hook or demonstration, and compare qualified follow-through rather than raw reach alone.

If viewers request a resource, make the destination accurate and useful. Define what they are signing up for, keep follow-up proportionate, and use supported platform permissions. A comment is not blanket permission for unrelated email marketing. Kiln did not connect an account, collect contacts or send DMs.

## Reusable prompt
```text
Create a two-week distribution experiment for this product and audience.
Use only the supplied product capabilities. Choose two channels at most,
define the first useful user action, draft three honest demo hooks, and
specify a cohort window and stopping rule. Separate visits, signups,
activation and retained use. Include time spent and support burden. Do not
invent revenue, testimonials, platform permissions or guaranteed outcomes.
```
